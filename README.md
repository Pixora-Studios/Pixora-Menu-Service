# The Tiny Table

White-label digital menu web application.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion & GSAP

## Setup
```bash
npm install
npm run dev
```

## Configuration
Branding and menu data can be customized in:
- `src/config/cafe.ts`
- `src/data/menu.ts`
